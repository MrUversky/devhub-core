# Support

DevHub is community-supported alpha software.

Before asking for help:

1. Read `docs/INSTALLATION.md` and `docs/CONFIGURATION.md`.
2. Run `npm run devhub -- validate --check` and `npm run devhub -- doctor`.
3. Search existing issues.

Use a bug report for reproducible defects and a discussion or feature request
for design questions. Include the DevHub version, Node.js or Docker version,
operating system, exact command and sanitized error output.

Do not attach your real catalog or paste internal hostnames, filesystem paths,
tokens, cookies, keys or connection strings. Reduce the problem to fictional
data first.

Security vulnerabilities and accidental data exposure belong in the private
channel described in `SECURITY.md`, not a public support issue.
